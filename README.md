# 로또 번호 생성기

지난 로또 6/45 당첨번호를 모으고, 패턴을 살펴보고, 그 패턴에 맞는 번호를 골라 준다.

## 핸드폰으로 쓰기
GitHub Pages 주소(https://guni0624.github.io/lotto/)를 핸드폰 브라우저로 열면 된다.
브라우저 메뉴의 "홈 화면에 추가"를 누르면 앱처럼 아이콘이 생긴다.

- `index.html` 핸드폰 화면. 추천 번호 뽑기, 패턴 분석, 추천 방식 검증이 다 들어 있다.
- `lotto_data.json` 지난 당첨번호. GitHub Actions(`.github/workflows/collect.yml`)가
  매주 일요일 아침 9시(한국 시간)에 새 회차를 받아 자동으로 넣는다.
- 당첨번호는 동행복권의 예전 조회 주소가 없어져서, 매주 당첨번호를 정리해 공개하는
  [smok95/lotto](https://github.com/smok95/lotto)에서 받는다.

## 컴퓨터에서 쓰기
파이썬만 있으면 된다 (따로 설치할 것 없음).

```
python lotto.py              모으기 → 분석 → 추천 5줄 (한 번에)
python lotto.py 수집          새로 나온 회차만 더 받아 오기
python lotto.py 분석          패턴 보기
python lotto.py 추천 10       추천 번호 10줄
python lotto.py 검증          추천 방식이 지난 100회에 실제로 얼마나 맞았는지 확인
python lotto.py 가져오기 파일.csv   동행복권 엑셀을 CSV로 저장한 파일 넣기 (자동 수집이 안 될 때)
```

받은 번호는 `lotto_data.json`에 저장되고, 다음부터는 새 회차만 받는다.

## 무엇을 보나
- 번호별 나온 횟수, 최근 50회에 많이 나온 번호, 오래 안 나온 번호
- 카이제곱 검정: 번호들이 고르게 나왔는지, 정말 잘 나오는 번호가 있는지
- 한 줄의 모양: 합계, 홀짝, 낮은/높은 번호, 이어진 번호, 같은 끝자리, 같은 10단위
- 같이 자주 나온 두 번호, 전 회차 번호가 또 나오는 정도

## 어떻게 고르나
1. 번호마다 무게를 준다: 전체 출현 횟수 + 최근 출현 횟수 + 오래 안 나온 정도
2. 무게대로 6개를 뽑고, 지난 당첨번호 대부분이 가진 모양만 남긴다
   (합계 가운데 80%, 홀짝 2~4개, 낮은/높은 2~4개, 이어진 짝 1쌍 이하, 같은 끝자리 2개 이하,
   한 10단위에 3개 이하, 이미 당첨된 적 있는 조합은 뺌)

## 꼭 알아 둘 것
로또는 매 회 독립된 무작위 추첨이라 지난 패턴이 다음 번호를 알려 주지 않는다.
이 프로그램은 '흔히 나오는 모양'의 번호를 골라 줄 뿐이고 당첨 확률은 아무 번호와 같다 (1등 1/8,145,060).
`검증`을 돌리면 추천 방식과 아무 번호가 비슷하게 맞는 걸 직접 확인할 수 있다.
